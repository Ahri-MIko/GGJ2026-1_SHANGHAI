# 配置说明：
# LevelName: 关卡名称
# StartTime: (关卡层级) 关卡延迟开始时间（秒），倒计时时长
# TotalRounds: 总轮次数
# Round: 轮次索引（从0开始）
# StartTime: (轮次层级) 该轮开始时间（从关卡正式开始后计时，秒）
# BPM: 每分钟节拍数（Beats Per Minute）
# Duration: 该轮持续时间（秒）
# BeatDuration: 每个节拍指示器的显示时长（秒），默认0.2秒

# 游戏机制：
# 1. 每轮开始时，7个球依次变蓝（间隔为BPM决定）
# 2. 每个球变蓝持续BeatDuration秒
# 3. 第7个球变蓝时，玩家需按空格键
# 4. 判定标准：±0.3秒=完美，±0.5秒=一般，其他=失误

# 时间线示例：
