# 游戏事件接收指南

## 快速开始

### 1. 基本结构

```csharp
using UnityEngine;

public class YourScript : MonoBehaviour
{
    // 在 Start 中注册事件
    private void Start()
    {
        EventCenter.Instance.AddEventListener<参数类型>(GameEvents.事件名, 回调函数);
    }
    
    // 在 OnDestroy 中注销事件（重要！）
    private void OnDestroy()
    {
        EventCenter.Instance.RemoveEventListener<参数类型>(GameEvents.事件名, 回调函数);
    }
    
    // 回调函数
    private void 回调函数(参数类型 data)
    {
        // 处理事件
    }
}
```

## 所有可用事件

### 1. 节拍事件 (OnBeatHit)
**触发时机**: 时间条到达节拍点时  
**参数类型**: `BeatHitData`

```csharp
private void Start()
{
    EventCenter.Instance.AddEventListener<BeatHitData>(GameEvents.OnBeatHit, OnBeatHit);
}

private void OnDestroy()
{
    EventCenter.Instance.RemoveEventListener<BeatHitData>(GameEvents.OnBeatHit, OnBeatHit);
}

private void OnBeatHit(BeatHitData beatData)
{
    Debug.Log($"节拍触发: Beat {beatData.BeatIndex}, Round {beatData.Round}");
    // beatData.BeatIndex - 节拍索引
    // beatData.Round - 回合数
}
```

---

### 2. 玩家判定事件 (OnPlayerJudgement)
**触发时机**: 玩家输入被判定时  
**参数类型**: `JudgementResult`

```csharp
private void Start()
{
    EventCenter.Instance.AddEventListener<JudgementResult>(GameEvents.OnPlayerJudgement, OnPlayerJudgement);
}

private void OnDestroy()
{
    EventCenter.Instance.RemoveEventListener<JudgementResult>(GameEvents.OnPlayerJudgement, OnPlayerJudgement);
}

private void OnPlayerJudgement(JudgementResult result)
{
    // 判定等级
    Debug.Log($"判定等级: {result.Level}"); // Perfect/Great/Good/Miss
    
    // 节拍索引
    Debug.Log($"节拍索引: {result.BeatIndex}");
    
    // 按键
    Debug.Log($"按键: {result.InputKey}"); // Q/W/E
    
    // 偏差时间
    Debug.Log($"偏差: {result.DeviationMs}ms");
    
    // 是否特殊判定
    if (result.Category == Category.Specific && result.Event != 0)
    {
        Debug.Log($"特殊判定！EventID: {result.Event}");
        // 可以根据 result.Event 获取事件详情
    }
}
```

## 重要提示

1. **必须注销事件**: 在 `OnDestroy` 中注销所有事件，避免内存泄漏
2. **类型匹配**: `AddEventListener<T>` 和 `RemoveEventListener<T>` 的类型必须一致
3. **回调函数签名**: 回调函数的参数类型必须与事件类型匹配
4. **使用示例脚本**: 可以直接使用 `EventReceiverExample.cs` 作为参考

## 常见使用场景

### 场景1: UI 控制器监听判定事件
```csharp
public class UIController : MonoBehaviour
{
    private void Start()
    {
        EventCenter.Instance.AddEventListener<JudgementResult>(
            GameEvents.OnPlayerJudgement, 
            OnPlayerJudgement
        );
    }
    
    private void OnPlayerJudgement(JudgementResult result)
    {
        // 更新 UI 显示
        UpdateScoreText(result.Level);
        ShowComboEffect(result.Level);
    }
}
```

### 场景2: 敌人控制器监听 Boss 行动
```csharp
public class EnemyController : MonoBehaviour
{
    private void Start()
    {
        EventCenter.Instance.AddEventListener<int>(
            GameEvents.OnBossAction, 
            OnBossAction
        );
    }
    
    private void OnBossAction(int eventId)
    {
        // 播放 Boss 动画
        PlayBossAnimation(eventId);
    }
}
```

### 场景3: 音效管理器监听多个事件
```csharp
public class SoundController : MonoBehaviour
{
    private void Start()
    {
        EventCenter.Instance.AddEventListener<string>(GameEvents.OnPlayVoice, PlayVoice);
        EventCenter.Instance.AddEventListener<int>(GameEvents.OnDoDMG, PlayDamageSound);
        EventCenter.Instance.AddEventListener<int>(GameEvents.OnCure, PlayHealSound);
    }
    
    private void OnDestroy()
    {
        EventCenter.Instance.RemoveEventListener<string>(GameEvents.OnPlayVoice, PlayVoice);
        EventCenter.Instance.RemoveEventListener<int>(GameEvents.OnDoDMG, PlayDamageSound);
        EventCenter.Instance.RemoveEventListener<int>(GameEvents.OnCure, PlayHealSound);
    }
}
```
